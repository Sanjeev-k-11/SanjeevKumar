## 📌 About the Project

This is a personal portfolio website designed to highlight my work as a **Full Stack Developer**.  
It includes sections like About, Skills, Projects, Resume, Training, Certificates, and Contact.

The website focuses on:
- Clean UI/UX ✨
- Smooth animations 🎯
- Responsive design 📱
- Professional presentation 💼

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Styling:** Tailwind CSS  
- **Animations:** AOS (Animate On Scroll)  
- **Email Service:** EmailJS  
- **Fonts:** Google Fonts  

---

## ✨ Features

- 🔥 Modern glassmorphism UI design  
- 📱 Fully responsive (Mobile + Desktop)  
- 🎯 Smooth scrolling navigation  
- 📊 Project showcase with live links  
- 📄 Resume view & download option  
- 📬 Contact form with EmailJS integration  
- ⚡ Fast and optimized performance
